# PRD

本目录存放 nano-personal-agent 的产品需求文档。

## 约定

- 每份 PRD 一个文件，命名：`PRD-<主题>.md`，例如 `PRD-001-核心对话能力.md`
- 按版本推进的 PRD 允许使用 `<版本> PRD.md` 命名，例如 `0.1 PRD.md`、`0.2 PRD.md`
- 每份 PRD 至少包含：背景与目标、用户场景、功能需求、非功能需求、验收标准、开放问题
- 需求变更直接更新原文档，并在文末「变更记录」中追加一行
